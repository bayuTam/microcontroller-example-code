# Microcontroller Projects

A collection of my microcontroller, IoT, embedded systems, and home automation projects.

This repository contains various experiments and projects built around **ESP32, Arduino, ESPHome, LoRa, Modbus, MQTT, Home Assistant, and Raspberry Pi**.

The projects range from simple hardware experiments to complete IoT integrations.

---

## 📂 Repository Structure

```text
microcontroller-example-code/
│
├── esp32/          # ESP32 based projects
├── arduino/        # Arduino and MCU projects
├── esphome/        # ESPHome configurations
├── raspberry-pi/   # Raspberry Pi / Python projects
├── node-red/       # Node-RED flows and integrations
│
├── docs/            # Documentation and technical notes
└── assets/          # Images, diagrams, and other assets
```
